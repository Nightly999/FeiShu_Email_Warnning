# Data Analysis

## 什么时候使用

当用户要求汇总、趋势、对比、排名、异常、风险、原因分析或数据解读时使用。

## 工作方式

1. 先判断用户要查询的业务对象、时间范围、筛选条件和统计口径。
2. 优先调用已提供的 MCP 工具获取真实数据。
3. 如果工具返回 `rows`，必须基于 `rows` 分析，不要说未查询到。
4. 先给业务结论，再给关键指标，最后给必要明细。
5. 多条明细、排名、对比、流程进度优先使用 Markdown 表格。
6. 字段和值较少时使用键值列表。

## 禁止事项

- 不要编造数据。
- 不要把原始 JSON 大段贴给用户。
- 不要要求用户提供 open_id、tenant_key、app_id。
